# OpsPilot · 工作台

## 1. 背景与目标

工作台用于构建、配置和发布 AI 机器人（Pilot）。机器人组装智能体、知识库与发布通道，对外提供对话能力，是 OpsPilot 面向用户的交付入口。

## 2. 范围定义

- 机器人：创建、配置、上下线、部署。
- 通道：发布到多种平台。
- 对话与日志：对话交互与会话日志。
- 统计与接口：用量统计与 API 访问。

## 3. 关键能力

- 机器人组装绑定的智能体（LLM + 提示词）与知识库（RAG），形成可对外服务的对话能力。
- 机器人类型支持：简单问答型、第三方对话界面型、多节点工作流型。
- 支持机器人的创建、配置、上线/下线与部署。
- **管理组织 / 使用组织授权**：机器人归属管理组织，管理组织可通过「授权使用组织」将对话能力开放给其它组织，被授权组织仅获得对话权，不获得管理权；管理组织始终具备使用权且不可被移除。详见第 4 节关键规则。
- 通道发布：支持企业微信、微信公众号、钉钉、Web、GitLab 等多通道，同一机器人可同时发布到多个通道。
- 工作流型机器人可在节点内生成文件附件（Markdown、PDF、Word），并向用户下发可下载的文件链接。
- 对话界面支持以卡片形式渲染节点产出，包括报告下载、配置差异报告、修复命令与用户选择。
- 通知（邮件）节点可将本次工作流生成的文件作为附件随通知一并发送。
- **测试执行与真实对话区分**：配置页发起的「测试」执行与线上真实对话相互独立——配置画布仅恢复展示测试发起的运行中执行，真实对话不回填到配置画布；同一机器人同时仅允许一个测试执行运行，真实对话流量不会阻塞测试。
- 支持查看会话日志（含用户/机器人消息与知识引用）；执行记录支持按「是否测试执行」过滤，区分配置页测试流量与真实对话流量。
- 支持用量统计：活跃用户/会话趋势、Token 消耗。
- 支持生成与管理 API 令牌，提供 OpenAI 兼容的对话接口供程序化接入。

## 4. 关键规则

- 仅上线状态的机器人接收用户消息；删除前需先下线。
- 机器人、智能体、知识库均按组织隔离。
- **机器人采用「管理组织 / 使用组织」二级授权模型**：
  - **管理组织**（team）：可在工作台查看、编辑、删除机器人，以及对外授权使用权；对话权限自动包含（因不变式 team ⊆ usage_team）。
  - **使用组织**（usage_team）：仅可调用对话接口进行对话，不能在工作台查看或管理机器人。
  - 机器人新建时，使用组织默认初始化为管理组织；管理组织恒为使用组织子集，不可从使用组织中删除。
  - 管理组织可通过「授权使用组织」操作将对话权开放给其它组织，被授权组织获得对话权但不获得管理权。
- 启用知识来源展示时，回答会标注引用的知识来源。
- 工作流生成的文件附件按执行实例隔离，凭下载令牌访问；同一执行实例内附件不重复，重新生成会替换旧文件。
- 附件仅支持 Markdown、PDF、Word 三类文件；邮件附件仅在通知类型为邮件时随通知发送。
- 工作流附件保留 3 天，到期由定时任务自动清理。
- **测试隔离规则**：配置页测试执行与真实对话执行完全隔离——仅本组织（管理组织）成员可发起测试执行；同一机器人同时只允许一个活跃的测试执行；被授权的使用组织不可发起测试执行；测试执行结果在配置画布中回填展示，不影响真实对话记录。
- 工作流执行记录可按「是否测试执行」过滤，以区分配置页测试与真实对话流量。
- **访问范围规则**：审批提交、选择提交、执行日志、执行节点结果与对话历史详情，均限定在调用者所属组织可见范围内；跨组织访问一律不可见（404）。

## 5. 关键技术架构选择

- 基于 LangChain/LangGraph 进行智能体编排。
- 工作流型机器人以多节点 DAG 引擎执行，支持流式响应、节点级执行追踪、人工审批与用户选择等人机协同节点，以及执行中断。
- 工作流附件由智能体节点通过内置工具生成并持久化，对话流中以事件下发下载链接，由前端渲染为对应卡片。
- 鉴权经系统管理校验令牌。对话接口按调用场景（测试/正常对话）分别按管理组织或使用组织过滤可用机器人。
- 人机协同决策接口（提交审批、提交选择）要求调用方携带有效 API Token，并校验目标执行实例归属调用方所在组织，拒绝跨组织伪造决策。详见 [[../../../ARD/modules/opspilot.md#33-人机协同接口认证变更submit_approval--submit_choice]]。

## 6. 验收标准

- 用户可创建机器人、绑定智能体与知识库并上线。
- 机器人可发布到多通道并对外提供对话。
- 管理组织可通过「授权使用组织」将对话权开放给其它组织；使用组织成员可调用对话接口，但无法在工作台查看或编辑机器人。
- 管理组织恒在使用组织内，授权操作不可将管理组织从使用组织中删除。
- 配置页测试执行仅管理组织可发起，同一机器人同时只允许一个测试执行；测试执行结果可在画布中回填，不影响正常对话记录。
- 执行记录列表支持按「是否测试执行」过滤，测试执行记录在结果中标识可辨。
- 提交审批、提交选择接口须携带有效 API Token 方可调用；跨组织伪造决策被拒绝（返回 404）。
- 会话日志、用量统计与 API 接入可正常使用。
- 工作流节点可生成文件附件，用户可在对话界面通过下载链接获取文件，邮件通知可携带该附件。
