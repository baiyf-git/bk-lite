## 1. 两件十月必须讲清楚的事

**可观测：** 相对计算 / 百分位能用表单配；保存前能看见会不会告。

**节点管理：** 采集器装得上、状态看得见、Monitor / Log / APM 接得上。

三域（Monitor、Log、APM）共用产品规则，**不共用扫描引擎**。维护窗 / 静默 / 级别抑制只进告警中心，不进各域策略表单。探针安装只进节点管理，不进三域列表页。

---

## 2. 三域共用规则

| 规则 | 含义 |
|---|---|
| 变化量 | 相对上一等长评估窗的 Δ 或 % |
| 短环比 | 当前评估窗整体平移 **1 小时 / 24 小时**。界面写「1 小时前同窗 / 24 小时前同窗」，**不写「昨天」** |
| 缺对照不误报 | 对照窗写不出、失败、尚未形成：本轮不触发，不当 0 |
| 试跑 | 未保存草稿即可；选实例；给出当前值 / 对照值 / 会不会命中；复用本域扫描引擎；**不落告警、事件、快照、通知** |
| 连续 N 次 | 试跑写明：「本轮计一次命中，未达连续次数则现网不会建告警」 |
| 试跑范围 | 只评当前窗，不是过去 24h 回放 |
| 百分位 | **只 Monitor 十月做**。APM 已是指标类型；Log 不做 |
| 运营降噪 | 维护窗 / 静默 / 级别抑制 / 通知编排 → 告警中心 |

## 3. Monitor（必须）

主题：【可观测·监控：策略能配 P95/环比，配完能试跑】

| # | 条目 | 十月承诺 | 说明 |
|---|---|---|---|
| 1 | 百分位 P90/P95/P99 | **必须** | 只放告警条件一个入口，不进现有窗口聚合下拉 |
| 2 | 变化量 + 短环比 | **必须** | 上一等长窗；1h / 24h 同窗；缺对照不误报 |
| 3 | 策略条件试跑 | **必须** | 未保存草稿；复用扫描引擎；不落单 |
| 4 | 滞回 + 无数据双窗 | **建议做** | 与试跑抢工时先砍第 4 条整条；默认恢复线 = 触发线 |

完整覆盖地图（保持 / 必做 / 建议做 / 可后置 / 不建议）见  
[`monitor-alert-calculation.md`](../../../docs/design/product-decisions/monitor-alert-calculation.md)。  
需求目录列出全部计算方式；档位才是承诺。对外**不写「对齐 Zabbix」**。

施工拆解见 [`monitor-oct-2026-plan/spec.md`](../monitor-oct-2026-plan/spec.md)。

## 4. APM（必须）

主题：【可观测·APM：相对变化能配、配完能验；看不见的调用不漏】

| # | 条目 | 十月承诺 | 说明 |
|---|---|---|---|
| 1 | 跨组织 Trace 详情按 Span 裁剪 | **必须** | 现网：任一可见 Span 会整条 Trace 返回，属安全漏洞 |
| 2 | 变化量 + 短环比 1h/24h | **必须** | 开在吞吐、错误率、P95/P99 上；缺对照不误报 |
| 3 | 策略条件试跑 | **必须** | 与 Monitor 同规则，用 APM 本域引擎 |
| 4 | 最低吞吐门槛 | **必须（相对计算的一部分，不可砍）** | 本窗请求数 ≥ N（默认 **20**，可改）。低于 N = 与缺对照相同：跳过，试跑写明跳过 |
| 5 | 探索后过滤分页 | 可选 | 有余量再做 |

不做：远程向应用进程注入语言探针（`ld.so.preload` / `javaagent` 推进进程）。接入制品下载归节点管理共背。

---

## 5. Log（必须）

主题：【可观测·日志：策略能配相对计算，配完能试算，告警能带样本回跳】

| # | 条目 | 十月承诺 | 说明 |
|---|---|---|---|
| 1 | 速率 / 变化量 | **必须** | 对照上一等长窗口；缺对照不误报。Log 速率 = 本窗 `count/period`，**不做** Monitor/APM 的 1h/24h 环比档 |
| 2 | 错误占比 | 可砍 | 仅 count；总量为 0 不触发 |
| 3 | 策略条件试算 | **必须** | 与 Monitor 同规则，用 Log 本域引擎 |
| 4 | 通知 + 详情 ≤10 条样本 + 回跳检索 | **必须** | 预填查询、日志分组、触发时间窗 |
| 5 | 组织级保存查询 | 现网已有 | 个人星标仅 W3 余力 |

**不要发明自动恢复**（已有决定）。Log 告警生命周期按现网，不在十月另造恢复状态机。

## 6. 节点管理（必须）

主题：【节点管理：探针装得上、状态看得见、三域接得上】

| # | 条目 | 十月承诺 | 说明 |
|---|---|---|---|
| 1 | 装完能验 | **必须** | 采集器是否在跑、最近心跳、失败原因说人话 |
| 2 | 覆盖一览（节点管理页） | **必须** | 主机 × Monitor / Log / APM 列；四态：**未安装 / 未下发 / 心跳异常 / 未接入**（采集器正常但无域实例）。不是单一「缺」 |
| 3 | `push_targets` 扩到 log + apm | **必须** | 节点 ↔ CMDB ↔ 三域实例 ID 对齐。「未映射」必须能在「未接入」之前测到。现网 `ALLOWED_PUSH_TARGETS = ("cmdb", "monitor")` |
| 4 | APM 接缝（与 APM 共背） | **必须** | 云区域区内 OTLP 接收面作为托管组件（安装 / 心跳）；接入页在区域收不到时告警；**系统内探针下载** + 现有复制粘贴片段。**不做**远程语言探针注入 |
| 5 | 批量升级 | 十一月（无余量） | 有余量再做，否则整条移十一月 |

## 7. 十月总表（排期一眼看完）

| 域 | 必须保住 | 可砍 / 后移 |
|---|---|---|
| Monitor | 百分位 + 变化量 + 1h/24h 同窗 + 试跑 | 滞回 / 无数据双窗；rate / 简化计数见覆盖地图建议做 |
| APM | Trace 按 Span 裁剪 + 变化量/短环比 + 试跑 + 最低吞吐门槛（相对计算内） | 探索分页 |
| Log | 速率/变化量 + 试算 + 样本回跳 | 错误占比；个人星标 |
| 节点 | 装完能验 + 四态覆盖一览 + push log/apm + 区内 OTLP 与探针下载 | 批量升级 |

3 周保两句话：**相对计算配完能验；机器装完能看见三域接上没有。**

---

## 8. 明确不做（四域共用）

- 维护窗 / 静默 / 级别抑制 / 通知编排进 Monitor / APM / Log / 节点策略或安装页
- 三域抽公共扫描库
- 试跑落告警、事件、快照或发通知
- 试跑做成 24h 历史回放
- 对外宣称「告警计算对齐 Zabbix」
- 远程向客户应用进程注入语言探针
- Log 自动恢复状态机
- Monitor 同比 / 统计基线 / 容量预测 / STL / Zabbix 函数全家桶（覆盖地图已列档位，不进十月施工）

---

## 9. 给评审会的短结论

十月做两件事：可观测策略能配相对计算并在保存前试跑；节点管理让采集器装得上、状态看得见、三域接得上。

Monitor 主保百分位、上一窗变化量、1h/24h 同窗环比、试跑。APM 主保跨组织 Span 裁剪、同样的相对计算与试跑，最低吞吐是相对计算的一部分不可砍。Log 主保上一窗速率/变化量、试算、样本回跳，不发明自动恢复。节点管理主保装完能验、四态覆盖一览、`push_targets` 扩到 log/apm、区内 OTLP 与系统内探针下载。

运营降噪继续只在告警中心。
