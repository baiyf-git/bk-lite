# 可观测告警计算方式丰富

Status: ready  
Audience: 产品 / 研发排期 / 售前对齐  
Scope: Monitor / APM / Log 策略判定（不含节点管理、不含告警中心运营）  
Horizon: 2026-10 起按档位交付；本文是三域计算方式**需求目录**，不是「一个月做完全表」

本文只写规划，不写业务代码。

---

## 1. 主题

**【可观测：告警计算方式丰富】**

腰部客户在 Monitor / APM / Log 用表单配「这个数怎么来、相对谁、怎么比线」，不必写 PromQL / Zabbix 表达式。竞品有的比较方式都列进需求，用档位标承诺；对外不写「对齐 Zabbix / Datadog」。

每种计算方式都是先算出一个数，再和阈值比。例外：无数据（没数）、试跑（先验）、明确不做的算法。

---

## 2. 共用规则

| 规则 | 口径 |
|---|---|
| 三域对齐 | 只对齐用词与规则，不抽公共扫描引擎 |
| 变化量 | 相对上一等长评估窗的 Δ 或 % |
| 短环比 | 当前评估窗整体平移 1 小时 / 24 小时。界面写「1 小时前同窗 / 24 小时前同窗」，不写「昨天」 |
| 缺对照 | 对照窗写不出、失败、尚未形成：本轮不触发，不当 0 |
| 百分位 | 只 Monitor 补计算方式。APM 已是指标类型 P95/P99；Log 不做 |
| 运营降噪 | 维护窗 / 静默 / 级别抑制 / 通知编排只进告警中心 |
| 试跑 / 试算 | **不是计算方式**。保存前先验：未保存即可；复用本域扫描引擎；不落告警、事件、快照、通知。连续 N 次须写明「本轮命中 ≠ 现网建单」。只评当前窗，不是 24h 回放。现网曲线/日志预览不算试跑 |

### 档位

| 档 | 含义 | 交付承诺 |
|---|---|---|
| **保持** | 现网已有，不回退 | 回归 |
| **十月必做** | 腰部闭环，缺了相对计算不敢用 | 进十月待办 |
| **建议做** | 明显增补，不挡主主张 | 可排期，落后必做一档 |
| **可后置** | 真有人要再做 | 不进近期待办，不对外承诺日期 |
| **不建议** | 明确不做 / 不承诺 | 仍写在表里，避免被当成遗漏 |
| **可砍** | 同迭代可滑出 | 仅 Log 错误占比 |

未标「十月必做」的不视为十月施工范围。工时只决定哪一档先做，不把「不建议」从需求里删掉。

## 3. Monitor

页面：基本信息 → **定义指标**（指标/公式、汇聚周期、汇聚方式）→ **告警条件**（阈值、触发、恢复、无数据）→ 通知。竞品主要对照 Zabbix 常用比较方式；实现不对齐触发器函数目录。

表内先已有、后缺失；十月必做排在缺失最前。试跑不计入计算方式。

| 计算方式 | 场景 | 竞品 | 状态 | 档位 | 页面位置 |
|---|---|---|---|---|---|
| 公式四则 | 简单多指标运算 | Zabbix 表达式更宽 | 已有（弱） | 保持，不强扩 | 定义指标 · 指标/公式 |
| avg / max / min / sum / count / last | 窗口聚合再比线 | Zabbix / PromQL 都有 | 已有 | 保持 | 定义指标 · 汇聚方式 |
| 固定阈值 / 绝对值 | CPU > 90% | 都有 | 已有 | 保持 | 告警条件 · 比较基准 + 阈值 |
| 多级阈值 | Warning / Critical | 都有 | 已有 | 保持 | 告警条件 · 阈值 |
| 连续 N 次触发/恢复 | 防毛刺 | 都有 | 已有 | 保持 | 告警条件 · 触发条件 / 自动恢复 |
| 无数据 | 采集掉线 | 都有 | 已有 | 保持（可打磨双窗） | 告警条件 · 无数据 |
| 百分位 P90/P95/P99（点值序列） | 延迟看尾部 | Zabbix `percentile` | 没有 | **十月必做** | 定义指标 · 汇聚方式 |
| 变化量（上一等长窗） | 比刚才多/少 | Zabbix 变化量；Datadog Change | 没有 | **十月必做** | 告警条件 · 比较基准 |
| 短环比 1h/24h 同窗 | 比 1 小时前 / 24 小时前同窗 | Datadog Change；Zabbix 对照窗 | 没有 | **十月必做** | 告警条件 · 比较基准 |
| 速率 rate | 计数器 → QPS/带宽 | Zabbix `rate` / `change` | 没有 | 建议做 | 定义指标 · 汇聚方式 |
| 条件计数（简化：窗内超阈点数 ≥ N） | 失败 > N 次 | Zabbix `count()` | 没有（可绕） | 建议做 | 定义指标 · 汇聚方式 |
| 滞回 | 触发/恢复不同阈值 | Zabbix 独立恢复表达式（不学整段） | 没有 | 建议做 | 告警条件 · 阈值 / 自动恢复 |
| 直方图分位 | bucket 真 P95 | Prom `histogram_quantile` | 没有 | 可后置 | 定义指标 · 汇聚方式 |
| 高阶统计 | 波动是否异常 | Zabbix stddev 一类 | 没有 | 可后置 | 定义指标 · 汇聚方式 |
| 变化次数 | 短时抖动 N 次 | Zabbix 窄函数 | 没有 | 可后置 | 定义指标 · 汇聚方式 |
| 同比更长 | 比上月/去年 | Zabbix / ARMS 日历同比 | 没有 | 可后置 | 告警条件 · 比较基准 |
| 统计基线 | 多季同期常态 | Zabbix 基线；Datadog Anomaly | 没有 | 可后置 | 告警条件 · 比较基准 |
| 容量预测 | 还有多久满 | Zabbix `forecast` / `timeleft` | 没有 | 可后置 | 告警条件 · 比较基准 |
| 长期趋势 | 天/周趋势 | Zabbix `trend*` | 没有 | 可后置 | 告警条件 · 比较基准 |
| 单调增/减 | 该涨却停 | Zabbix 窄函数 | 没有 | 可后置 | 告警条件 · 比较基准 |
| 季节分解 STL | 去季节后的异常 | Zabbix `trendstl` | 没有 | **不建议** | 告警条件 · 比较基准（明确不做） |
| 试跑 | 保存前看会不会告 | Grafana Preview | 没有 | 十月必须 | **先验按钮，不是计算方式** |
| **计数** | | | **已有 6 / 缺 15** | **共 21 种计算方式**（缺 15 含不建议 1，待补 14） | 试跑不计入 |

十月 Monitor 施工：百分位 + 变化量 + 1h/24h 同窗 + 试跑。滞回 / rate / 简化计数落后一档。

百分位和 avg 同一槽（汇聚方式）；变化量 / 环比在告警条件比较基准，和阈值叠加，不是互斥下拉。十月百分位是点值序列分位，不是直方图。

## 4. APM

页面：基本信息 → **指标定义**（服务、指标、汇聚周期、汇聚方法）→ **告警条件**（阈值、触发、恢复、无数据）→ 通知。现网只有绝对值。P95/P99 已是指标类型。竞品主要看 Datadog APM Monitor、阿里云 ARMS、Grafana。

表内先已有、后缺失；十月必做排在缺失最前。试算不计入计算方式。

| 计算方式 | 场景 | 竞品 | 状态 | 档位 | 页面位置 |
|---|---|---|---|---|---|
| 指标：错误率 | 本窗错误占比 | Datadog / ARMS / Grafana | 已有 | 保持 | 指标定义 · 指标 |
| 指标：P95 / P99 | 尾部时延 | Datadog 还有 P50/P75/P90 | 已有 | 保持（不再做 Monitor 那种百分位计算方式） | 指标定义 · 指标 |
| 指标：吞吐 | QPS | 都有 | 已有 | 保持 | 指标定义 · 指标 |
| 指标：无流量 | 没请求 | Datadog 可配低于阈值 | 已有 | 保持 | 指标定义 · 指标 |
| 汇聚 avg / last / max / min | 窗收成一个数 | 都有 | 已有 | 保持 | 指标定义 · 汇聚方法 |
| 固定阈值 | 当前值比一条线 | 都有 | 已有 | 保持 | 告警条件 · 阈值 |
| 多级阈值 | Warning / Critical | 都有 | 已有 | 保持 | 告警条件 · 阈值 |
| 连续 N 次触发/恢复 | 防毛刺 | Grafana pending | 已有 | 保持 | 告警条件 · 触发条件 / 自动恢复 |
| 无数据 | 窗内没样本 | 都有 | 已有 | 保持 | 告警条件 · 无数据 |
| 变化量（上一等长窗） | 比刚才多/少 | Datadog Change | 没有 | **十月必做** | 告警条件 · 比较基准 |
| 短环比 1h/24h 同窗 | 比 1 小时前 / 24 小时前 | Datadog Change；ARMS 上小时/昨日 | 没有 | **十月必做** | 告警条件 · 比较基准 |
| 最低吞吐门槛 | 错误率/P95 在低流量下不评 | Datadog min requests | 没有 | 建议做（见第 7 节） | 告警条件 · 比较基准旁路（AND） |
| 指标：P50 / P75 / P90 / 平均时延 | 更全的时延分位 | Datadog Threshold | 没有 | 可后置 | 指标定义 · 指标 |
| 指标：Apdex | 满意度 | Datadog | 没有 | 可后置 | 指标定义 · 指标 |
| 日历同比（昨天同时段） | 自然日对齐 | ARMS「昨日」 | 没有 | 可后置 | 告警条件 · 比较基准 |
| 滞回 | 触发线和恢复线分开 | 部分产品有 | 没有 | 可后置 | 告警条件 · 阈值 / 自动恢复 |
| 容量/趋势预测 | 还要多久坏 | Datadog Forecast | 没有 | 可后置 | 告警条件 · 比较基准 |
| SLO 燃烧率 | 错误预算烧太快 | Datadog SLO | 没有 | 可后置 | — |
| 异常检测 / Watchdog | 偏离季节常态 | Datadog Anomaly | 没有 | **不建议** | — |
| 离群（相对其他服务） | 这台比同伴差 | Datadog Outlier | 没有 | **不建议** | — |
| 任意 AND/OR 复合条件 | 多指标自由拼 | Datadog Composite | 没有 | **不建议**（十月最多一条最低吞吐 AND） | — |
| 试算 | 保存前看会不会告 | Grafana Preview | 没有 | 十月必须 | **先验按钮，不是计算方式** |
| **计数** | | | **已有 9 / 缺 12** | **共 21 种计算方式**（缺 12 含不建议 3，待补 9） | 试算不计入 |

十月 APM 施工：变化量 + 1h/24h 同窗（开在吞吐、错误率、P95/P99）+ 试算。跨组织 Trace 按 Span 裁剪是同期必须交付的安全项，**不是计算方式**，不进上表。

## 5. Log

页面：基本信息 → **设置告警条件**（查询、聚合规则、周期、级别；没有单独「定义指标」）→ 通知。关键字无阈值，聚合只有绝对值。竞品主要看 Datadog Log Monitor、Grafana、夜莺、ARMS 日志。

表内先已有、后缺失；十月必做排在缺失最前。试算、样本回跳不计入计算方式。

| 计算方式 | 场景 | 竞品 | 状态 | 档位 | 页面位置 |
|---|---|---|---|---|---|
| 关键字命中 | 窗内匹配就告 | Datadog log count；夜莺 | 已有 | 保持 | 设置告警条件 · 查询（无阈值） |
| 聚合 count / sum / max / min / avg + 固定阈值 | 条数或字段聚合比线 | Datadog count/measure；Grafana | 已有 | 保持 | 设置告警条件 · 规则 |
| 速率（本窗 count/period） | 每秒/每分钟多少条 | Datadog 窗内 count；夜莺速率 | 没有 | **十月必做** | 设置告警条件 · 计算方式 |
| 变化量（上一等长窗） | 比刚才多/少 | Datadog Change | 没有 | **十月必做** | 设置告警条件 · 比较基准 |
| 错误占比（error count / 总量） | 错误比例 | Datadog 两查询相除 | 没有 | **可砍**（仅 count；总量 0 不触发） | 设置告警条件 · 计算方式 |
| 短环比 1h/24h | 比 1 小时前 / 24 小时前 | Datadog Change；ARMS | 没有 | 可后置（十月故意不做，避免和 Monitor/APM 同词） | 设置告警条件 · 比较基准 |
| 去重/基数（unique count） | 多少个独立用户/IP | Datadog facet unique | 没有 | 可后置 | 设置告警条件 · 规则 |
| 数值字段百分位 | 日志里 duration 的 P95 | Datadog measure pc95 | 没有 | 可后置 | 设置告警条件 · 规则 |
| 无日志 / 低于 N 条 | 该来的日志没来 | Datadog below | 没有 | 可后置 | 设置告警条件 · 阈值 |
| 新值 / 新模式 | 从没见过的字段值 | 部分日志平台 | 没有 | 可后置 | — |
| 连续 N 次 | 防毛刺 | Monitor/APM 有 | 没有 | 可后置 | — |
| 无数据（采集断） | 和「无日志」不同 | Monitor 有 | 没有 | 可后置 | — |
| 异常 / 突增检测 | 相对常态暴涨 | Datadog Anomaly（常先转指标） | 没有 | **不建议** | — |
| 自动恢复 | 条件不满足就翻回 | Monitor/APM 有 | 没有 | **不建议**（不发明自动恢复） | — |
| 样本 + 回跳检索 | 告警带 ≤10 条并跳回查询 | Datadog 通知可带样本 | 没有 | 十月必须 | **通知 / 详情，不是计算方式** |
| 试算 | 保存前看会不会告 | Grafana Preview | 没有 | 十月必须 | **先验按钮，不是计算方式** |
| **计数** | | | **已有 2 / 缺 12** | **共 14 种计算方式**（缺 12 含不建议 2，待补 10） | 试算、样本不计入 |

十月 Log 施工：速率 + 上一窗变化量 + 试算 + 样本回跳。错误占比可砍。不做 1h/24h 环比档，不发明自动恢复。

## 8. 明确不做（三域共用）

- 维护窗 / 静默 / 级别抑制进各域策略表单
- 三域公共扫描库
- 试跑落告警或发通知；试跑做成 24h 历史回放
- 对外宣称告警计算对齐 Zabbix / Datadog 函数全集
- Monitor / APM / Log 做季节分解、Watchdog、离群、任意 AND/OR 复合条件
- Log 自动恢复状态机
